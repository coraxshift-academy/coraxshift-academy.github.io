The DevOps learning path

12 weeks from zero to deployed

Each week builds on the last. By the end, you'll understand how modern software is built, shipped and kept running.

WEEK 01

Essentials

Internet, networking, tools

Follow a website request from your browser to a server. Meet DNS, IP and HTTP.

WEEK 02

Linux

Linux and Nginx

Get comfortable in the terminal, serve a web app, read logs and learn safe permissions.

WEEK 03

Bash

Shell automation

Automate a health check and a verified backup, and make scripts safer before they run.

WEEK 04

Git

Git and GitHub

Work in branches, open pull requests, review changes and resolve conflicts with confidence.

WEEK 05

SDLC

Plan, test, release

Turn an idea into a tested change, with a release plan and a way to roll it back.

WEEK 06

Terraform

Infrastructure as code

Describe infrastructure in code, review a plan and understand state, without cloud costs.

WEEK 07

Ansible

Configuration automation

Set up servers consistently and prove your automation is safe to run twice.

WEEK 08

Docker

Containers and Compose

Package an app and its database. Master images, networks, health checks and data.

WEEK 09

AWS

Cloud foundations

Understand identity, networking and costs, then deploy safely with a cleanup plan.

WEEK 10

Kubernetes

Orchestration

Run apps with Deployments, Services and probes, and write a practical runbook.

WEEK 11

CI/CD + Observability

Delivery and operations

Test every change automatically, watch how your app behaves and plan recovery.

WEEK 12

Capstone

Integrate and present

Bring it all together, explain your design, demonstrate recovery and celebrate.
